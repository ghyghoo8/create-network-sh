## 当前工具与配置

- 读取类 23 个、写入类 23 个，总计 46 个。
- `GITEE_MODE=READ` 可见 23 个读取入口；`WRITE` 可见全部 46 个。
- 官方 MCP 25 个工具，网关 REST 补充 19 个；另有 whoami 和兼容的 create_private_project。
- 前端支持现代 MCP 协议，Gitee 后端固定 legacy 模式，解决旧版 tools/list 响应的校验问题。
- Python 3.14.4，FastMCP/fastmcp-slim 4.0.11，MCP 2.3.0。
- 网关仅监听 `127.0.0.1:8765`；ngrok 入口为
  [固定域名](https://mcp.example.com)，插件路径为 `/mcp`。
- 凭据只在目标服务器的私有 `.env` 中配置；本目录仅保留空模板。

## 启停与日志

```bash
cd /opt/gitee-mcp-gateway/gateway
chmod 755 start.sh stop.sh
./start.sh
```

首次使用先在原来的 gateway/ngrok 前台终端分别 Ctrl+C。
停止用 `./stop.sh`；重复启动会复用已核验的进程。

`logs/control.log` 记录 UTC 启停事件、运行 ID、PID 和结果。
`logs/gateway.latest.log`、`logs/ngrok.latest.log` 指向最近的服务输出；
每次启动生成独立日志，停止后保留。日志覆盖服务生命周期和进程输出。

SSH 断开后继续运行；服务器重启后手动 start。
当前 OAuth/JWT 状态在内存中，gateway 真正重启后需重新连接插件。
本版不设置开机自启或自动拉起。
